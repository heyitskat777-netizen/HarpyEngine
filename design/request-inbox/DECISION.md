# Selected direction

The owner selected the recommendation: **A — overview inbox, opening B — guided
review**. This supersedes the earlier B-only selection in this conversation.

`/character requests` opens five request/task summaries per page with native
Pending / Needs you / Waiting / History controls and a category filter. The
request dropdown opens its version-bound detail, effect preview and role-specific
actions. Back returns to the overview. Previous / Next navigate pages in the
overview and individual requests in review; Refresh reloads saved state.

Coordination tasks route to existing authorized wizards. Stale versions and rapid
repeat clicks cannot authorize a different request. Runtime authority remains the
backend; the standalone synthetic browser comparison is design evidence.

The intended Play picker is recorded in `design/play-picker/README.md`. Actual
Play resolution and scene-channel locking are future work, not inbox side effects.
