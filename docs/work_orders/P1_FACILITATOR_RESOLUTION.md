# P1 human-facilitator vertical slice

Root owns engine/p1_facilitator, services/p1_facilitator, finite native view and notification worker, additive0015 standalone outbox, and shared integration. Existing real required-work histories store request revisions; no fake roll/Action is created to carry a notice. Campaign configuration is an explicitly administrator-authored user-or-role assignment event; role notifications never grant blanket private-source access. Native requester explicitly shares only their own request text; public notices carry only request ID and configured mention.

A real joined scene, owned actual pending Action or owned required-work row supplies source ID/revision, rule, original actor, immutable known receipt and affected context. Mandatory work remains required. Ruling is auditable advice; fictional effects still use their existing validated owner-operated service. The finite completion adapter verifies actual source Action completion or real source-work resolution and original receipts; a missing effect adapter remains blocked, never narration-completed. Optional scene requests alone may be declined. New Plays in that scene are blocked by pending request; an existing actual Play retains its existing Discord lock. Source-free scene pause uses the same mergeable permission snapshot operations via a separate request-scoped notice job, preserving source-only Game action identity.

Notification worker uses durable lease, stable nonce and reconciliation; uncertain delivery stays visible and cannot imply exactly-once Discord posting. It sends only in the source channel with AllowedMentions restricted to designated recipient. Configuration/delivery blockers remain visible. Resume rechecks configuration, request/state revisions, source/receipt, original owner, real dependencies and effect completion. Snapshot restoration must preserve unrelated permission edits.

Minimum likely-flow smoke only during development; owned/private/restart/stale/receipt and blocked-adapter normal tests are retained for final P1. No model key, unsolicited private DM, arbitrary database effect setters, global pause, live deployment or whole-rules claim.
