# Session Zero campaign launch

Session Zero members approve the same short-term goals and difficulty draft.
The approved Handler completes setup with a written introduction and an
existing campaign text channel. Opening the scene, applying the approved
difficulty, and recording the fictional roleplay window are atomic.

The introduction is a roleplay scene with an explicit audience. It defaults
to three fictional days. The Handler explicitly advances each introductory
day through the campaign calendar. The first mission opens only after that
window and has one clear objective. Existing mission acceptance and rules
apply, and regular missions follow after the introductory mission completes.

Narrative restricts Execution, Lobotomization and Indefinite Imprisonment,
and protects original player characters from lethal outcomes. Normal uses the
existing rules. Hard starts with the same simple mission, then requires a
specific additional obstacle in the briefing before players accept each
subsequent mission. This is a campaign design setting with no extra rulebook
modifiers.

## Discord flow

1. In `/session-zero`, the appointed Handler opens **Draft goals and
   difficulty**. The plan is shown privately to every group member. Approvals
   refer to that specific draft and can be withdrawn before completion.
   Editing the plan starts a fresh approval round.
2. After all approvals and current sheet attachments, the Handler selects
   **Complete and open introduction**. They choose an existing text channel,
   write their own introduction, and choose two to seven fictional days.
   Three is the default. The introduction and channel link appear in every
   group member's Session Zero panel and worksheet.
3. The group roleplays in that channel. The introductory scene is reserved
   for roleplay. The Handler uses **Advance one roleplay day** when the group
   is ready for the next day. The calendar checks the same pending work,
   safety and phase gates as a chapter cut. Advancing the calendar does not
   perform an Off-Duty transition.
4. At the end of the opening window, the Handler uses `/mission offer` with
   one clear starting objective. The normal player acceptance and dispatch
   steps open a playable mission scene in the original channel. The accepted
   Pilots still join the scene themselves. Settle existing consequences and
   finish the first mission before offering another.

The approved difficulty takes effect on completion. Legacy campaigns use
Normal. Narrative protects active Pilots, the player Handler, and tracked
player Harpy bodies from lethal outcomes. Unsupported lethal outcomes stay
pending for adjudication. Narrative never invents a substitute or changes a
saved die result. Ordinary NPC combat remains governed by the existing rules.
Hard expects a concrete obstacle such as a washed-out extraction route or a
stated deadline. It records the obstacle in the briefing each invited player
reviews before accepting.

The offline patch uses HarpyEngine's existing SQLite schema and command inbox.
Session Zero can open a roleplay introduction with complete saved sheets.
Gameplay, mission dispatch, and active scene participation retain their
existing release and character-activation checks.
