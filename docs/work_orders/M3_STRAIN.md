## Implemented scheduling

High-track set. The canonical GameState holds the three tracks and append-only
game history supplies rebuild authority. Existing saves with no Strain state do
not receive a guessed scenario.

At actual Off-Duty start, the Handler supplies a complete factual trigger review.
Void facts must agree with current canonical Assets; present Frame damage cannot
be denied, and a claimed clean successful mission requires a recorded completed
success. Facts about the still-unimplemented world remain explicitly human
attestations in private work history, not newly invented entities or proof that
their mechanics ran. All start booleans have explicit required answers.

DoctorDoctor owners record actual credit or no-trigger first. High Budget marks
Obsolescence once using the resulting severity; eight boxes queue the real owned
compulsory replacement package flow in the same Off-Duty context.

Each track has its own pending d6 request. Confirmation saves its actual face
before either event column can be selected. Reading/reopening does not draw dice.
The two short source summaries are labels; complete effects become separate
blocking required work. Column 2 of High row 6 schedules both severity rolls or an
unused Endgame as dictated by the recorded campaign counting interpretation.
Parents, remaining recursive requests, used slots and exact receipts survive
restart/backup/rebuild. A batch boundary must not discard remaining work.

`/mission strain`, `/mission off_duty` and the private Off-Duty request category
offer native owned selectors. Missing effect support has no “done” override.
No current live registration, migration or M3 approval is implied.
