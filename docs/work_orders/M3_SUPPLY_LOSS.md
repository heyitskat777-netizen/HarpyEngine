# M3E/F — actual missed shipment and pre-roll recovery modifier

Status: implemented offline within RULES_SUBSET; full-candidate checks and
independent/human acceptance remain separate. Sources: book PDF 150 / printed
p.148 (Low Budget 3/2), ordinary recovery PDF 27 / printed p.25, Observation
PDF 28 / printed p.26, and the logged `supply_observation` campaign interpretation.

The current Handler describes the actual missing resource and confirms the saved
Strain effect. An OS-backed uniform index chooses from the complete actual Cadre
population, with no recipient selector or name-based identity. Preserve the real
character references, population/index, source event and period privately. The
assignment is committed once and cannot be redrawn through reopening, replay,
concurrent commands or a later roll. A failed uncommitted transaction remains a
rollback, without fabricating a known draw/receipt.

The selected Girl receives a separate −2 pre-roll modifier for the actual recovery
period. The delegated recommendation also applies it when Void Observation replaces
Go Off-Duty; its alternative and pending clarity review are recorded centrally.
The effect is bound before any period Play, shown privately before confirmation,
and consumed with the real locked roll. Unrolled cancellation leaves it assigned;
known-roll recovery retains its consumption, dice and already answered humans.
Changed character incarnations cannot enter the original draw or inherit its loss.

Keep base Status/Void Assets, the supply penalty and post-roll Tag/Bond modifiers
separate. Raw and final receipts and saved period rolls retain each adjustment
without applying it twice. Ordinary and Observation tiers use the actual adjusted
total. Private source text/populations are not public receipt payloads; the Handler
and affected owner receive only their permitted factual projections.

Native Strain input requests the resource/account, never a recipient. The real Play
confirmation previews the penalty. The scene and saved-receipt views display base
and supply arithmetic. Source-ledger, policy, game/character revision, safety,
chat-lock and idempotency boundaries remain shared with existing Plays.

Acceptance: unbiased OS primitive and strict draw bounds; actual population and
source ownership; no forged target or hidden-text leak; all result tiers;
Observation and post-roll Bond effects; concurrent/replayed application;
resource/receipt rollback; unrolled cancellation; restart/rebuild/known-roll resume;
new characters; native controls and explicit displayed receipt arithmetic. Tests
are `tests/rules/test_supply.py` and `test_supply_service.py`. Other temporary
modifiers, playbook passives and remaining Strain/world/economy rules still need
their actual typed consumers; this module does not claim those mechanics complete.
