# Actual NPC hurt cohorts

Baseline: harpyengine-p1-relay-advice-integrated-20261111. Source: Easy Target,
rulebook PDF41/printed39, matched against the local current source and existing
registry. The baseline explicitly rejected any cohort on an actual NPC hurt
source with REQUIRED_NPC_HURT_COHORT_ADAPTER; existing use/protection cohorts did
not close that route. This slice connects the printed high-result cohort choice
to existing NPC bodily performance, actual Newgirl-owned injury and Punishment.

After original Handler validation, original cohorts privately record actual
bodily participation or decline. Participation requires the original scene,
controller, live/free/co-located body, exposed Pilot body if applicable, and no
prior NPC hurt attempt. It grants only matching Easy Target consequence exemption,
not damage, a roll, Heat, defense, anatomy, consent or unrelated immunity. The NPC
still performs through its own source control and the Newgirl still selects one
actual legal Girl Asset injury. Existing interception and required damage work
remain real. Actual harm completes performed cohorts alongside the primary;
intercepted attempts preserve the outstanding ordinary hurt obligation.

Other nominees cannot block the actual NPC performance. Their later owned
acknowledgment records a missed opportunity with no retroactive exemption or
alteration of damage/Punishment. Nonparticipants never become fabricated helpers.
The new immutable HurtCohort record uses the existing fact/history/response
mechanism, with no schema migration. Historical proof uses snapshot profile/body
and scene bindings, not later scene identities or account roles. Private native
readback includes the original participation outcome/account. The separate
source-specific module keeps the existing generic Play and damage ports intact.

Production files: engine/m3_easy_target.py; services/m3_easy_target.py;
services/m3_easy_target_hurt_cohort.py; discord_adapter/m3_easy_target.py.
Registry adds the delegated source interpretation and maintains clarity review.
A few local names in the touched existing Easy Target apply function were changed
to remove pre-existing conflicting mypy inference; there is no behavior change
for those use/protection paths.

Authored normal test has two source-result variants, not a role/lifecycle matrix:
- Actual native high source, NPC hurt and independently owned participation,
  another decline, another missed acknowledgment, real injury, no Punishment,
  no extra roll/receipt or proxy resource changes, and native private historical
  reopen after a real scene change.
- Same actual NPC harm with no participant: missed/declined nominees grant no
  exemption, and the Newgirl's ordinary selected/executed Punishment remains.

The reusable fixture's initial map, NPCs, roles and resources are synthetic setup;
all source choices, validation, participation, NPC performance and injury use real
services/native forms. No cohort, exemption, injury or outcome is injected.
The one privacy canary and owned replay guard use existing test infrastructure.
